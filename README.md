# Venu Skillset Plugin Development

This repository is the version-controlled source for the Venu Skill Library.

## Layout
- `skills/` — canonical Venu Skills plus `_cross-cutting/` extensions.
- `benchmarks/` — benchmark/evaluation artifacts.
- `SKILL-REGISTRY.json` — machine-readable registry.

Canonical library: 53 Skills (47 technical/AI + 6 Business Mastery).
Cross-cutting modules such as guardrails, voice/observability, Blender MCP, and AAR remain extensions unless promoted into the canonical registry.
