# Venu Skill Quality Standard — 10/10 Target

Research snapshot: 2026-09-01

“10/10” is a release target, not a claim of omniscience or guaranteed correctness. It requires source traceability, actionable workflows, explicit contracts, security controls, failure/recovery behavior, observability, version awareness, composability and reproducible evaluation.

Current foundational anchors include the Agent Skills specification, the 2026-07-28 MCP specification update, NIST AI RMF, OWASP Top 10:2025, DORA 2025 and OpenTelemetry semantic conventions.
